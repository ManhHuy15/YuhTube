# Design Taste Frontend (Anti-Slop Taste Framework)

## Overview & The Taste Mandate

Frontends generated by AI tools frequently suffer from "AI Slop": lazy, generic layouts with zero personality, arbitrary spacing, and uncalibrated animation. 

The **Design Taste Frontend** framework mandates that all frontend work is governed by explicit design taste dials, strict layout constraints, and tactile micro-interactions.

---

## The Three Dials Framework

For every page, module, or component you design or touch, calibrate the **Three Dials (Scale 1–10)**:

### 1. `DESIGN_VARIANCE` (1 to 10)
*Defines structural layout asymmetry, unpredictability, and visual drama.*
- **Low (1–3)**: Rigid grid, data tables, uniform settings panels.
- **Medium (4–6)**: Balanced asymmetric split (e.g. YouTube Studio: 7-col forms + 5-col sticky video preview card, floating bottom mini-tray).
- **High (7–10)**: Experimental editorial, heroic landing pages, staggered masonry.
*👉 **YuhTube Target**: **5–6** (Structured creator productivity with modern cinematic polish).*

### 2. `MOTION_INTENSITY` (1 to 10)
*Defines frequency, duration, and choreography of transitions and feedback.*
- **Low (1–3)**: Instant snap, zero fluff, strictly functional.
- **Medium (4–6)**: Tactile transitions (150ms–300ms ease), smooth progress bar fills, slide-in-from-bottom floating tray, micro spin loaders.
- **High (7–10)**: Parallax, complex layout physics, heavy scroll-driven reveal.
*👉 **YuhTube Target**: **5** (Smooth, reactive, never lagging user input).*

### 3. `VISUAL_DENSITY` (1 to 10)
*Defines information density and data-to-whitespace ratio.*
- **Low (1–3)**: Airy, marketing landing page with massive padding.
- **Medium (4–6)**: Standard consumer application.
- **High (7–9)**: Pro-creator workstation, video editor, developer IDE, analytics cockpit.
*👉 **YuhTube Target**: **7** (Pro-grade information density: compact badges, inline stats, timecodes, tabbed workflows, zero bloated dead space).*

## Anti-Slop Prohibitions

1. **NO Cookie-Cutter Feature Grids**: Do not generate 3 equal-width boxes with an icon on top, a header, and 2 lines of lorem ipsum.
2. **NO Ghost/Floating Borders Without Contrast**: All dark cards must have a sharp, visible structural boundary (`border border-white/10` or `border-white/15`), grounded by solid canvas `#0e0e10`.
3. **NO Unanchored Floating Dropdowns**: Dropdowns, popovers, and menus must feature backdrop-blur, subtle elevation shadows, and clear directional anchors.
4. **NO Dead Ends**: Every state (uploading, draft, empty comments, zero likes) must offer an immediate, obvious, satisfying path forward.

---

## Craft & Interaction Checklist

- [ ] **Hover & Press**: All interactive elements respond with tactile feedback (`hover:bg-white/10`, `active:scale-95`).
- [ ] **Living Progress**: Progress indicators use gradient fill (`from-red-600 to-[#69d8d4]`) with transitions (`duration-300`).
- [ ] **Status Clarity**: Cloud sync, saving draft, and upload progress are surfaced with unmistakable visual indicators.
- [ ] **Responsive Grace**: Layouts adapt seamlessly from mobile viewports to ultra-wide displays without horizontal blowout.
